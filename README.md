InovaIF - Landing Page de Vendas
Este projeto consiste no desenvolvimento de uma Landing Page profissional para a Feira de Empreendedorismo e Inovação (InovaIF). O objetivo principal é a divulgação e venda de cursos, utilizando uma estrutura moderna, responsiva e otimizada para conversão.
🚀 Objetivo do Projeto
Desenvolver uma estrutura de landing page genérica e robusta, preparada para receber informações de clientes reais no ecossistema de empreendedorismo, focando em:

    Rastreabilidade via Git/GitHub.
    Colaboração em equipe através de branches e Pull Requests.
    Experiência do usuário (UX) e design responsivo.

🛠️ Estrutura e Funcionalidades
O site foi construído seguindo rigorosamente os requisitos mínimos exigidos:

    Cabeçalho (Header): Identidade da marca, cronômetro regressivo de oferta e design flutuante.
    Seção de Vídeo: Apresentação principal com controle de execução (bloqueio de navegação durante a exibição para garantir o foco no conteúdo).
    Certificações: Exibição de selos de qualidade e reconhecimentos acadêmicos.
    Passos para o Objetivo: Guia em etapas sobre como o serviço ajuda o cliente.
    Características do Produto: 6 cards interativos destacando os diferenciais.
    Utilidade: Aplicações práticas e resultados esperados.
    Feedbacks e Avaliações: Prova social com depoimentos de clientes.
    Autores: Informações sobre a equipe de desenvolvimento e responsáveis.
    Dúvidas e Garantia: FAQ (Perguntas Frequentes) e política de satisfação.
    Venda: Área de conversão com preço, parcelamento e CTA (Call to Action).
    Rodapé (Footer): Informações institucionais e direitos autorais.
    WhatsApp: Botão flutuante para suporte direto ao cliente.

💎 Melhorias Implementadas (Plus)
Além dos requisitos básicos, o projeto recebeu refinamentos técnicos avançados:

    Responsividade Total: Media queries customizadas para Mobile, Tablet e Desktop.
    Tipografia Fluida: Uso da função CSS clamp() para textos que se ajustam automaticamente ao tamanho da tela.
    Design Moderno: Efeitos de vidro (Glassmorphism), transições suaves (transitions) e elevações em hover.
    Semântica HTML5: Estrutura otimizada para SEO e acessibilidade.
    Performance: CSS puro e JavaScript leve, garantindo carregamento rápido.

💻 Tecnologias Utilizadas

    HTML5: Estruturação semântica.
    CSS3: Estilização avançada, Flexbox, Grid e animações.
    JavaScript: Lógica do cronômetro, controle de vídeo e interatividade dos cards.

🔄 Fluxo de Trabalho (Git/GitHub)
O projeto foi desenvolvido seguindo as melhores práticas de versionamento:

    Setup: Inicialização com git init e configuração de .gitignore.
    Branches: Desenvolvimento organizado por funcionalidades (ex: feature/header, feature/venda).
    Colaboração: Uso de Pull Requests para revisão de código.
    Histórico: Commits semânticos e organizados para auditoria (git log --oneline).
